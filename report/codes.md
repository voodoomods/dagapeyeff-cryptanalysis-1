## Appendix D. Case-file codes

Every bracketed code in this report, such as [F78], is an entry in the project's case file — the running record in
which each result is written down with its evidence. The letter gives its
kind: **F** an established fact, **R** a system or idea ruled out, **I** a result that is suggestive but not conclusive,
**C** a convention — chiefly prior work and how we credit it — and **O** an open question or lead. All entries below except F73 and R34 (retired)
have the status *confirmed*, given by one of the case's designated confirmers (Turing, the review board or the
developer) — in most cases the same hand that recorded the entry; O33 stays confirmed as a record, but its wording is
superseded by O34. None has yet been reviewed outside the project. The full text of each, with its evidence and review history, is in `evidence/case/dagapeyeff.json` in
the repository; where a result file is listed, it is in the repository too.
